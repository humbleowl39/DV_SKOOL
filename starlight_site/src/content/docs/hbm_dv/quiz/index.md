## 사용법

1. 챕터 본문을 학습한 후 해당 퀴즈로 이동
2. 정답을 정한 뒤 **"정답 / 해설"** 을 펼쳐 확인
3. 틀린 문항은 본문의 해당 절을 다시 학습

## 서술형 문항에 대하여

이 코스에는 선택지 없이 **서술로 답하는 문항**이 많습니다. 실무의 판단에는 정해진 보기가 없기 때문입니다. 해설과 표현이 달라도, **판단의 근거가 같다면 맞은 것**으로 보셔도 됩니다.
