각 챕터의 핵심을 Bloom's Taxonomy 분포로 점검합니다 — **암기 / 이해 / 적용 / 분석 / 평가 / 창작**.

이 코스의 퀴즈는 **조문 암기가 목표가 아닙니다.** 규격의 한 줄에서 **무엇이 깨질 수 있고 그것을 어떻게 잡는지**까지 답할 수 있는지가 기준입니다. 정답을 맞혔더라도 *"그래서 checker·coverage·시퀀스에서 무엇이 달라지는가"* 를 말하지 못하면 아직 절반입니다.

특히 **"이 결함은 언제 잡히는가"** 를 함께 답해 보세요. 이 코스에서 반복해 나온 답은 *"명시적으로 검사하지 않으면 안 잡힌다"* 또는 *"실리콘"* 입니다.

## 사용법

1. 챕터 본문을 학습한 후 해당 퀴즈로 이동
2. 답을 정한 뒤 **"정답 / 해설"** 을 펼쳐 확인
3. 계산 문항은 **실제로 계산**해 볼 것 — 규격의 관계식은 손으로 따라가야 몸에 붙는다
4. 틀린 문항은 본문의 해당 절과 **🔬 검증 적용** 절을 함께 다시 본다

:::tip[우선순위]
시간이 부족하면 **08 · 09 · 12** 를 먼저 푸세요.

- **08 Parity** — "차단하지 않는다"가 에러 주입 이후 기대값을 어떻게 어렵게 만드는가
- **09 ECC·ECS·SEV** — `ERRTH` 필터가 만드는 관측성 구멍, `NE ≠ 오류 없음`
- **12 종합** — 12개 장의 검증 항목과 **디지털 회귀로 검증할 수 없는 다섯 항목**

이 셋이 "무엇을 검증할 수 있고 무엇을 검증할 수 없는가"를 가장 직접적으로 다룹니다.
:::
