## Q1. (Remember)

TSV 는 무엇의 약자이며 무엇을 하는가?

- [ ] A. Transistor Stack Via — 트랜지스터를 쌓는 구조
- [ ] B. Through-Silicon Via — 실리콘 다이를 수직으로 관통해 위아래 면을 잇는 배선
- [ ] C. Thermal Silicon Vent — 열을 빼는 통로
- [ ] D. Two-Sided Vertical — 양면 배선

<details>
<summary>정답 / 해설</summary>

**B**. Through-Silicon Via — "실리콘을 관통하는 통로"입니다.

C 가 오답이지만 부분적으로는 맞는 이야기입니다 — TSV 는 구리이므로 **열도 나릅니다.** 신호를 나르지 않는 열 전용 TSV 를 일부러 배치하기도 합니다([07장](../../07_thermal/)).

</details>

## Q2. (Understand) ★

와이어 본딩처럼 다이 **테두리**에 패드를 놓는 방식으로는 HBM 을 만들 수 없는 근본적 이유는?

- [ ] A. 금선이 비싸기 때문
- [ ] B. 테두리 길이는 다이 크기에 비례하지만 필요한 신호 수가 그보다 훨씬 많기 때문
- [ ] C. 와이어 본딩은 고속 신호를 전달할 수 없기 때문
- [ ] D. 테두리에는 회로를 놓을 수 없기 때문

<details>
<summary>정답 / 해설</summary>

**B**.

```
테두리 길이 = 4L   →  다이 크기에 비례
면적       = L²    →  다이 크기의 제곱
```

한 변 10 mm 다이의 테두리에 40 µm 간격으로 패드를 놓으면 **약 1,000개**입니다. 그런데 HBM4 스택 하나가 호스트와 주고받는 신호는 **약 3,900개**입니다 — **네 배 부족**합니다.

같은 다이의 면적에 50 µm 격자로 TSV 를 놓으면 **약 40,000개** 자리가 나옵니다.

**왜 중요한가**: ★ **주변부가 아니라 면적을 쓴다**는 것이 이 장의 핵심입니다. 신호 수를 자릿수 단위로 늘리려면 면을 써야 하고, 면을 쓰려면 수직 관통해야 합니다.

C 도 부분적으로는 사실이지만 근본 원인은 아닙니다.

</details>

## Q3. (Understand)

TSV 와 µbump 의 차이를 옳게 설명한 것은?

- [ ] A. 같은 것의 다른 이름이다
- [ ] B. TSV 는 다이 안을 관통하는 세로 배선, µbump 는 다이 사이를 붙이는 접점이다
- [ ] C. TSV 는 신호용, µbump 는 전원용이다
- [ ] D. TSV 는 상단 다이에만, µbump 는 하단 다이에만 있다

<details>
<summary>정답 / 해설</summary>

**B**. 신호는 둘을 **번갈아** 지납니다 — 다이 안에서는 TSV 를, 다이 사이에서는 µbump 를 통과합니다.

덧붙여, **최상단 다이에는 TSV 가 필요 없습니다** — 더 위로 올려보낼 신호가 없기 때문입니다.

</details>

## Q4. (Apply) ★

TSV 지름이 5 µm 이고 제조상 종횡비(깊이 ÷ 지름) 상한이 10:1 이라면 다이 두께는 얼마 이하여야 하는가? 그리고 갓 나온 다이가 700 µm 라면 종횡비는 얼마가 되는가?

<details>
<summary>정답 / 해설</summary>

```
뚫을 수 있는 최대 깊이 = 5 µm × 10 = 50 µm
→ 다이 두께가 50 µm 이하여야 한다

700 µm 두께에 지름 5 µm 구멍 → 종횡비 140:1  → 제조 불가
```

**결론: 쌓으려면 다이를 갈아서 수십 µm 로 만들어야 합니다.**

**왜 중요한가**: 이 한 줄에서 세 가지가 파생됩니다.

| 파생 | 결과 |
|---|---|
| 얇은 다이는 **기계적으로 취약** | 휘고 깨진다 → 수율 위험 |
| 얇은 다이 여러 장이 붙어 있다 | **열이 갇힌다** |
| 실리콘 단면이 줄었다 | 열을 **옆으로 퍼뜨리기도** 어렵다 |

★ **"쌓으려면 얇게 → 얇으면 열이 문제"** — 이 고리가 [07장](../../07_thermal/)에서 마무리됩니다.

</details>

## Q5. (Analyze)

TSV 는 전기적으로 PCB 배선보다 훨씬 좋은 배선이다. 그 이유와, 주된 기생 성분이 무엇으로 바뀌는지 설명하라.

<details>
<summary>정답 / 해설</summary>

**길이가 약 1,000배 짧습니다** — PCB 수 cm 대 TSV 수십 µm. 그리고 얇고 넓적한 띠가 아니라 **굵은 기둥**(지름 5~10 µm)입니다.

| | PCB 배선 | TSV |
|---|---|---|
| 저항 | 길이에 비례해 큼 | **작다** |
| 인덕턴스 | 큼 | **작다** |
| 주된 기생 성분 | 저항·인덕턴스·유전 손실 | **커패시턴스** |

**커패시턴스가 주된 성분이 되는 이유**: 실리콘은 절연체가 아니므로 도체와 실리콘 사이에 **절연막**을 끼워야 합니다. 도체 – 절연막 – 실리콘 구조는 곧 **커패시터**입니다.

**왜 중요한가**: [02장](../../02_memory_wall/)의 세 문제(감쇠·번짐·반사)가 사실상 사라지고, 남는 것은 작은 커패시턴스를 구동하는 전력뿐입니다. 그래서 **비트당 에너지가 매우 낮고**, 이것이 HBM 이 낮은 전송률로도 큰 대역폭을 낼 수 있는 물리적 근거입니다.

</details>

## Q6. (Evaluate)

"TSV 는 많으면 많을수록 좋다"는 주장을 평가하라.

<details>
<summary>정답 / 해설</summary>

**틀렸습니다. 면적과 용량의 맞바꿈이 있습니다.**

TSV 는 그 자리에 회로를 놓을 수 없게 만듭니다. 구멍 자체의 면적뿐 아니라, 구멍을 뚫고 금속을 채우면 주변 실리콘에 응력이 걸려 트랜지스터 특성이 변하므로 **주변에도 회로를 두면 안 되는 영역**(keep-out zone)이 생깁니다.

그래서 **TSV 를 늘리면 셀을 놓을 자리가 줄어 용량이 깎입니다.**

**추가로 치르는 대가 둘**:

- **기계적 취약** — 50 µm 실리콘은 잘 깨지므로 모든 공정 단계에서 수율 위험
- **접합부 고장** — 스택 하나에 신호 접점이 수천 개이고 층마다 반복되므로 **통계적으로 결함이 반드시 생긴다**

마지막 항목 때문에 HBM 규격은 **여분 신호선과 복구 수단을 명시적으로 배정**합니다. 이 규모에서 복구 기능은 있으면 좋은 것이 아니라 **반드시 있어야 하는 것**입니다.

</details>
