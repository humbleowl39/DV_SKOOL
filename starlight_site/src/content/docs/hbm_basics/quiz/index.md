읽고 넘어가는 것과 설명할 수 있는 것은 다릅니다. 각 챕터의 퀴즈는 "알고 있다"고 느끼는 것과 실제 이해 사이의 간격을 드러내기 위해 설계되었습니다. Bloom's Taxonomy 분포를 적용해 **기억 / 이해 / 적용 / 분석 / 평가** 수준의 문항이 섞여 있습니다.

이 코스의 퀴즈는 **숫자를 외웠는지 묻지 않습니다.** *"왜 그렇게 되는가"* 와 *"그래서 무엇이 따라오는가"* 를 답할 수 있는지가 기준입니다.

## 사용법

1. 챕터 본문을 학습한 후 해당 퀴즈로 이동
2. 답을 정한 뒤 **"정답 / 해설"** 을 펼쳐 확인
3. 계산 문항은 **실제로 계산**해 볼 것 — 이 코스의 숫자는 대부분 외우는 것이 아니라 유도되는 것이다
4. ★ 표시 문항은 그 장에서 가장 뒤집히기 쉬운 지점이다

:::tip[이 코스에서 가장 자주 뒤집히는 셋]
세 문장이 코스 내내 반복해서 교정됩니다. 퀴즈를 풀며 이 셋을 확인하세요.

1. **"HBM은 빠른 메모리다"** → 핀당 속도는 GDDR보다 **낮다.** 빠른 게 아니라 **넓다** (02장)
2. **"쌓으면 대역폭이 올라간다"** → 쌓기가 늘리는 것은 **용량**이다. 대역폭은 폭에서 나온다 (02·05장)
3. **"거리를 줄였으니 지연도 줄었다"** → 전파 지연은 **처음부터 병목이 아니었다.** 얻은 것은 에너지와 폭 (06장)
:::
