각 챕터의 핵심 개념 이해도를 확인합니다. Bloom's Taxonomy 분포를 적용해 **암기 / 이해 / 적용 / 분석 / 평가** 수준의 문항이 섞여 있습니다.

이 코스의 퀴즈는 지식 확인이 목적이 아닙니다. **면접에서 그 답을 소리 내어 말할 수 있는가**가 기준입니다. 정답을 맞혔더라도 해설의 *왜*를 30초 안에 설명하지 못하면 아직 준비된 것이 아닙니다.

## 사용법

1. 챕터 본문을 학습한 후 해당 퀴즈로 이동
2. 정답을 **머릿속이 아니라 입으로** 정한 뒤 "정답 / 해설"을 펼쳐 확인
3. 틀린 문항은 본문 해당 절을 다시 학습
4. 면접 시뮬레이션 — 해설을 보지 않고 **30초~1분 안에 말로** 설명. 핵심 문항은 **영어로도** 답해 본다

:::tip[우선순위]
시간이 부족하면 **03 · 05 · 07** 세 개를 먼저 푼다. 공고의 무게중심(Custom Agent · Coverage Closure · 즉석 작성)이 그 셋에 있다.
:::
