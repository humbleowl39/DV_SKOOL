## 사용법

1. 챕터 본문을 학습한 후 해당 퀴즈 페이지로 이동
2. 정답을 머릿속으로 정한 뒤 **"정답 / 해설"** 영역을 펼쳐 확인
3. 틀린 문항은 본문의 해당 절을 다시 학습

## 계산 문항에 대하여

이 코스에는 계산을 요구하는 문항이 여러 개 있습니다. 전부 다음 한 줄에서 파생됩니다.

> **per-stack 대역폭 (GB/s) = 총 버스 폭 (bit) × per-pin 속도 (Gb/s) ÷ 8**

암기가 목적이 아니라, **공개 자료의 수치가 서로 충돌할 때 무엇이 옳은지 스스로 판정하는 능력**을 기르는 것이 목적입니다.
